# Feature Spec Template

## Summary

One paragraph, plain language: what this feature does and why.

## Acceptance criteria

Bulleted list of observable outcomes that define "done".

## Affected surfaces

Which files, modules, or layers will change.

## Data shapes

Any new types, API request/response shapes, or database schema changes.

## Out of scope

What this change explicitly does not include.

## Open questions

Anything unresolved that needs a decision before or during implementation.
